# Comedy Examples — Analysis Log

This file tracks the actual analysis of examples from `2025_power_rankings.md` (or anything else
you paste in) — the distilled lessons that get folded into `src/prompts.py`, not just a copy of
the source material. Also not read by the running app at runtime; same reasoning as
`2025_power_rankings.md`.

For each strong example pulled from the source material, record:

- **What happened** — the underlying real event/stat
- **What the joke's premise was** — the actual comedic idea, not just the insult
- **Why it was funny** — what made the construction work
- **Where the punchline landed** — setup vs. payoff structure
- **What factual context made it work** — what grounding it needed
- **Callback?** — did it reference a prior week, and how
- **Target: manager or team?** — second-person/personal vs. third-person/descriptive
- **What made it non-generic** — the detail that couldn't be pasted into another league
